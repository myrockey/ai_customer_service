📌 这是第三方接入示例页面（SDK 方式）

本页面模拟一个电商网站，演示如何通过 SDK（cs-chat.js） 接入智能客服系统。
右下角 💬 客服 按钮由 SDK 自动渲染，点击即可打开客服对话窗口。
接入流程：服务端用 app_key/app_secret 换 token → 前端引入 SDK 并传入 token → SDK 自动管理浮窗按钮、弹窗、WebSocket 连接、消息收发。
SDK 内部用 iframe 加载 pc.html，对外提供 open/close/sendText/on 等 API。
