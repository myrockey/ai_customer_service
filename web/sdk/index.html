⚠️ 接入注意事项

  • user_id 必须带租户前缀：格式为 {tenant_id}:{uid}，否则鉴权失败（如 t_demo:user_12345）
  • app_secret 只能存在服务端：前端不能暴露 app_secret，必须通过后端换 token 后传给前端
  • PC 端用 SDK：引入 cs-chat.js，自动渲染浮窗按钮，体验最好
  • 移动端用 h5/chat.html：全屏页面，已适配安全区域、触摸优化、返回按钮
  • token 有效期 24 小时：建议服务端缓存 token，提前 30 分钟刷新
  • 小程序需要配置业务域名：在微信公众平台添加客服系统域名到白名单
  • App WebView 必须开启 JS 和 DOM 存储：否则页面无法正常运行
  • SDK 版本化（P1-5）：推荐用带版本号的 URL /sdk/cs-chat@2.0.0.js（服务端已配置别名，始终指向当前版本）。SDK 升级后只需修改 URL 中的版本号，即可强制刷新第三方浏览器缓存，避免旧代码残留
